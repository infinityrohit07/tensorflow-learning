# Notebooks

Store learning notebooks in this folder.

Naming format: `NN-short-topic-name.ipynb`

Examples:
- `01-introduction-to-machine-learning.ipynb`
- `02-tensorflow-and-tensors.ipynb`
- `03-neural-network-fundamentals.ipynb`

Use one main topic per notebook. Keep explanations in Markdown cells and executable examples in code cells.
