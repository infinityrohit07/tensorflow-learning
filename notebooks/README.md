# TensorFlow Learning Notebooks

This folder contains my structured TensorFlow learning notes and practical code examples.

Each notebook covers a specific topic, organised into learning phases to maintain a clear progression from fundamentals to deep learning.

---

## Learning Roadmap

### Phase 1 — Foundations

Introduction to machine learning and the TensorFlow environment.

| Notebook | Topics Covered |
|---|---|
| `00_Understanding_tensorflow_and_machine_learning.ipynb` | Introduction to machine learning, deep learning, neural networks, and TensorFlow |
| `01_Understanding_tensorflow_environment.ipynb` | TensorFlow environment and basic setup |

### Phase 2 — TensorFlow Fundamentals

Understanding tensors, their properties, creation methods, and operations.

| Notebook | Topics Covered |
|---|---|
| `02_Understanding_Tensors_Rank_Shape_and_Dimensions.ipynb` | Tensor rank, shape, dimensions, and data types |
| `03_Creating_tensors_in_tensorflow.ipynb` | Different ways of creating tensors |
| `04_tensor_operations.ipynb` | Arithmetic operations, broadcasting, matrix multiplication, transpose, reshape, and reductions |
| `05_tensor_manipulation.ipynb` | Indexing, slicing, expand dimensions, squeeze, casting, argmax, and argmin |
| `06_randomness_and_reproducibility.ipynb` | Random normal, uniform, random seeds, reproducibility, random initialization, and numerical precision |

### Phase 3 — TensorFlow and NumPy Interoperability

Understanding how TensorFlow interacts with NumPy arrays and Python data structures.

| Notebook | Topics Covered |
|---|---|
| `07_tensorflow_and_numpy_interoperability.ipynb` | Tensor-to-NumPy conversion, NumPy-to-tensor conversion, eager execution, and combined operations |

---

## Notebook Naming Convention

Use the following naming format:

`NN_short-topic-name.ipynb`

---

## Learning Guidelines

- Keep one main topic per notebook.
- Use Markdown cells for explanations and theoretical notes.
- Use code cells for executable examples and experiments.
- Include practical exercises wherever appropriate.
- Maintain the learning order from fundamentals to advanced concepts.
